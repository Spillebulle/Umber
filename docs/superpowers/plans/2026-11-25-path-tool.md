# The Path Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Path tool that draws cut and plot paths point by point with curve handles and edits any existing path, one undo entry per finished gesture.

**Architecture:** Pure geometry in `umber-core::pathedit`. A window-free state machine in `umber-app::pathtool` that is fed presses, moves, releases and keys in document space and answers a `Commit`. `Editor` turns a commit into a record swap and an undo entry through project 1's `set_vector` and `Edit::vector`. `gesture.rs` gains `Press::Path`; `app.rs` routes; `ui.rs` paints from the tool's own copy, so the layer's record is written once, at the release.

**Tech Stack:** Rust, glam `Vec2`, egui (painting only), existing `umber_core::vector`.

**Spec:** `docs/superpowers/specs/2026-11-25-path-tool-design.md`. Read it; it is the authority.

**Branch:** `path-tool`, cut from `vector-layers`, in the worktree `C:/Users/spill/AppData/Local/Temp/umber-wt/vector`. `CARGO_TARGET_DIR` is `<worktree>/target`, set on every invocation.

```rust
pub const SMOOTH_DEGREES: f32 = 1.0;
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum Side { In, Out }
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct SegmentHit { pub segment: usize, pub t: f32, pub at: Vec2, pub distance: f32 }

/// Nearest node within `radius`, nearest first; ties to the lower index.
pub fn node_at(path: &Path, at: Vec2, radius: f32) -> Option<usize>;
/// Which handle tip of `node` is within `radius`. A zero handle is never hit.
/// Both in reach: the nearer; a tie goes to `Out`.
pub fn handle_at(node: &Node, at: Vec2, radius: f32) -> Option<Side>;
/// Nearest point on the path's curve within `radius`. Culls a cubic whose
/// control-point box, grown by `radius`, misses `at`, before sampling it.
/// `segment` indexes `Path::segments()`, so the closing segment is last.
pub fn segment_at(path: &Path, at: Vec2, radius: f32) -> Option<SegmentHit>;
/// Split `segment` at `t` by de Casteljau. Returns the path and the new
/// node's index. The curve does not move. A straight segment gives a corner.
pub fn split(path: &Path, segment: usize, t: f32) -> Option<(Path, usize)>;
/// Remove node `i`. `None` when what is left is fewer than two nodes, or a
/// closed path of fewer than three: the path goes.
pub fn without_node(path: &Path, i: usize) -> Option<Path>;
pub fn is_smooth(node: &Node) -> bool;
/// Put one handle's tip at offset `to`. With `mirror` and a smooth node the
/// other handle turns to stay opposite, keeping its own length.
pub fn with_handle(node: Node, side: Side, to: Vec2, mirror: bool) -> Node;
pub fn cornered(node: Node) -> Node; // both handles zero
/// Handles along prev->next, each a third of the distance to its own
/// neighbour. `None` for an end node of an open path or a path under three nodes.
pub fn smoothed(path: &Path, i: usize) -> Option<Node>;
pub fn moved(path: &Path, by: Vec2) -> Path;   // nodes move, handles do not
/// Node order reversed, each node's handles swapped. Same curve.
pub fn reversed(path: &Path) -> Path;

// vector.rs, on VectorObject. Each refuses an Opaque record and re-runs check().
pub fn with_path(&self, index: usize, path: Path) -> Result<Self, VectorRefusal>;
pub fn without_path(&self, index: usize) -> Result<Self, VectorRefusal>;
// `appended` already exists.
```

```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum PathMode { Draw, Edit }
impl PathMode { pub const ALL: [PathMode; 2]; pub fn label(self) -> &'static str; } // "Draw", "Edit"

/// Document-space distances for this press, from the camera.
#[derive(Clone, Copy, Debug)] pub struct Reach { pub hit: f32, pub tap: f32 }

/// What the tool may touch on this event.
#[derive(Clone, Copy)]
pub struct Ground<'a> {
    /// The active layer's record, only where `Editor::editable_paths` gave one.
    pub paths: Option<&'a VectorObject>,
    pub reach: Reach,
    /// False when more than the cap of the picked path's nodes are in view.
    pub nodes_shown: bool,
}

#[derive(Clone, Debug, PartialEq)]
pub enum Commit {
    Nothing,
    /// Finished paths to land. The draft stays up until `landed` is called.
    Land { paths: Vec<Path>, replaces: Option<usize> },
    /// The active layer's whole record after an edit.
    Set(VectorObject),
}

#[derive(Clone, Debug)]
pub struct Draft { pub nodes: Vec<Node>, pub closed: bool, pub continues: Option<usize> }

pub struct PathTool { pub mode: PathMode, pub role: PathRole, /* private: draft, pick, drag, hover, said */ }
impl Default for PathTool // Draw, PathRole::Cut, nothing up

impl PathTool {
    pub fn draft(&self) -> Option<&Draft>;
    pub fn hover(&self) -> Option<Vec2>;
    /// The sentence to show until the next press, if any.
    pub fn said(&self) -> Option<&'static str>;
    /// A press. `edit` is `mode == Edit || ctrl`.
    pub fn press(&mut self, at: Vec2, edit: bool, ground: Ground<'_>);
    /// The pointer moved, held or not. `alone` is Shift.
    pub fn moved(&mut self, at: Vec2, alone: bool);
    pub fn release(&mut self, at: Vec2, ground: Ground<'_>) -> Commit;
    pub fn is_held(&self) -> bool;          // between a press and its release
    pub fn finish(&mut self) -> Commit;     // Enter
    pub fn pop(&mut self) -> bool;          // Backspace, Delete or Undo with a draft up
    pub fn abandon(&mut self) -> bool;      // Escape; true when it consumed the key
    pub fn settle(&mut self) -> Commit;     // tool change, tab switch, close, resize, flip
    /// The outcome of the last `Commit::Land`. Ok clears the draft; Err keeps
    /// it up and sets `said`.
    pub fn landed(&mut self, outcome: Result<(), &'static str>);
}
```

Rules (spec, "Draw mode"): a press with no draft and `!edit` first asks `ground.paths` for an **open** path whose first or last node is within `reach.hit` (first match in path order, last node preferred when both ends of one path are in reach); if found the draft is that path's nodes (reversed with `pathedit::reversed` when the first node was hit), `continues = Some(index)`, and no node is added by that press. Otherwise the press appends `Node::corner(at)` and the draft's `role` is the tool's. While held, `moved` sets the last node's `handle_out = at - node.at`, `handle_in = -(at - node.at)`; a `release` within `reach.tap` of the press zeroes both. A press within `reach.hit` of `nodes[0]` with three or more nodes sets `closed` and its release returns `Commit::Land`. `finish` returns `Land` with two or more nodes, else `Nothing` and leaves the draft. `settle` returns `Land` with two or more nodes (and the caller must call `landed`; on `Err` the caller drops the draft with `abandon`), else drops the draft and returns `Nothing`. `pop` removes the last node; removing the only node ends the draft; with `continues` set, popping below the continued path's own node count abandons the draft instead (the path on the layer is untouched). The landed `Path` has `role` = the continued path's role, or the tool's; `ink: None`; `pressure: 1.0`.

Press order with `edit` true and `ground.paths = Some(record)` (spec, "Edit mode"), first match wins: (1) `ground.nodes_shown` and a handle of the picked node via `pathedit::handle_at`; (2) `nodes_shown` and `node_at` on the picked path; (3) `segment_at` on the picked path; (4) nearest `segment_at` over every other Cut or Plot path (Ink is never hit); (5) let go. `ground.paths == None` -> the press does nothing at all. A drag works on a clone of the one path taken at the press, each `moved` recomputing from the press state (absolute, not accumulated). `release`: case 3 within `reach.tap` -> `pathedit::split` and pick the new node; otherwise the dragged path if it differs from the original. The commit is `Commit::Set(record.with_path(i, path))`; a `with_path` error sets `said` to the refusal's `sentence()` and returns `Nothing`. A release that changed nothing returns `Nothing`. `set_role` with no pick sets `self.role` and returns `Nothing`; with a pick it changes that path only and never `self.role`. `remove` with a node picked uses `without_node`, falling to `without_path` when that answers `None`, and clears the node (or the whole pick). `abandon` (Task 3) now also lets go: node first, then path, one per call, after any draft. A pick whose `path` index is off the end of `ground.paths` is dropped at the next call that takes a `Ground`.
